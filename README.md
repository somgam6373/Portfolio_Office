# 🖥️ 3D Interactive Office Scene

> **OpenGL 기반의 기술 집약형 3D 인터랙티브 오피스 공간 구현 프로젝트** > 단순한 3D 모델 배치를 넘어, 그래픽스 파이프라인 최적화, 고급 렌더링 기법, 그리고 다양한 유저 인터랙션을 유기적으로 연결한 그래픽스 프로젝트입니다. 본 프로젝트는 효율적인 협업을 위해 **복도 씬(Corridor Scene)**과 **사무실 내부 씬(Office Scene)**으로 역할을 분할하여 고도화를 진행했습니다.

---

## 👥 팀원 소개 및 역할 분담

### 🔸 이고은 (팀장) | 복도 씬(Corridor Scene) 총괄 & 최적화
* **정점 데이터 최적화:** 오브젝트 특성에 따라 **8-float / 14-float VAO 포맷을 분리**하여 GPU 데이터 전송량 최소화.
* **다중 점광원 시스템:** 3개의 포인트 라이트에 **Blinn-Phong 모델 및 이차 감쇠(Quadratic Attenuation)**를 적용하여 사실적인 광량 변화 구현.
* **절차적 노멀 매핑:** **TBN 행렬** 기반 탄젠트 공간 변환 및 CPU 단에서 **4옥타브 노이즈를 합성하는 절차적 생성(Procedural Generation)** 방식으로 벽면/바닥 요철 표현.
* **고급 물리/셰이더 효과:** 도어 핸들에 **Cook-Torrance PBR 셰이더**(GGX NDF, Smith-Schlick, Schlick Fresnel) 적용, **지오메트리 셰이더** 기반 유리 화병 폭발 연출.
* **동적 이펙트:** 280개 파티클 기반의 **빌보드(Billboard) 먼지 시스템** 및 사인 함수 기반의 **강아지 동적 메시 애니메이션** 구현.

### 🔹 이준혁 | 사무실 내부 씬(Office Scene) 총괄 & 파이프라인
* **멀티 패스 렌더링 파이프라인:** 매 프레임 5단계 패스(Directional/Point 섀도우 맵 ➡️ HDR 씬 렌더 ➡️ MSAA Resolve ➡️ 후처리 톤 매핑) 구축.
* **하이브리드 조명 및 그림자:** 태양광(Directional) 및 천장·플로어 램프(Point)를 포함한 **3종 4개 광원 큐브맵 그림자** 처리.
* **카메라 시스템 & 충돌 검사:** 사일 함수 기반 **카메라 워킹(Wobble 효과)** 및 가구별 **AABB 충돌 박스** 구현으로 뚫림 방지.
* **에셋 제어 및 알파 블렌딩:** **Assimp 라이브러리** 활용 외부 모델 제어, 창문 반투명 유리 **알파 블렌딩**, **해석적 햇빛 패치(가우시안 분포/가산 블렌딩)** 구현.
* **레이 캐스팅 인터랙션:** 화면 중앙 Ray와 AABB 교차 판정을 통한 가구/액자 호버링 감지 및 **스텐실 테스트 기반 외곽선(Outline) 강조**, URL 연동.

## 🚀 핵심 구현 기술 (Technical Features)

### 1️⃣ 멀티 패스 렌더링 파이프라인 (Multi-Pass Rendering Loop)
안정적이고 사실적인 그래픽 표현을 위해 매 프레임마다 총 5단계의 패스를 거쳐 최종 화면을 출력합니다.
1. **Directional Light 섀도우 패스:** 태양 시점에서 직교 투영으로 깊이 정보만 FBO에 저장해 방향광 그림자 계산.
2. **Point Light 섀도우 패스:** 사방으로 발산하는 천장 조명을 위해 큐브맵 6면에 깊이 정보를 저장해 360도 그림자 생성.
3. **HDR 씬 렌더 패스:** 오프스크린 FBO에 MSAA 4샘플로 씬을 그리며 앞서 만든 두 그림자와 Blinn-Phong 조명을 결합.
4. **MSAA Resolve:** 픽셀당 4개 샘플을 `glBlitFramebuffer`로 평균내어 계단 현상을 제거하는 안티에일리어싱 완성.
5. **후처리 패스:** 풀스크린 쿼드에 결과를 입혀 밝기 보정(Tone Mapping) 후처리를 거쳐 최종 디스플레이에 출력.

### 2️⃣ 그래픽스 최적화 및 PBR 재질 (Optimization & Physics)
* **VAO/VBO 포맷 이원화:** 법선 매핑이 필요 없는 일반 오브젝트(8-float)와 노멀 매핑용(14-float) 구조를 엄격히 분리하여, 불필요한 탄젠트/비탄젠트 데이터가 GPU 버퍼로 전송되는 병목 현상을 해결했습니다.
* **Cook-Torrance PBR:** 금속 재질인 도어 핸들의 사실성을 극대화하기 위해 미세 표면 반사 분포를 위한 **GGX NDF(D)**, 자기 가림을 처리하는 **Smith-Schlick 지오메트리 항(G)**, 입사각에 따른 반사율을 계산하는 **Schlick Fresnel 항(F)**을 모두 반영했습니다.

### 3️⃣ 절차적 생성 및 해석적 광원 연출 (Procedural & Analytical)
* **Procedural Normal Map:** 외부 이미지 텍스처 의존도를 낮추기 위해 CPU에서 직접 픽셀 데이터를 제어하여 석고 표면 노이즈(4옥타브 합산)와 패널 홈 경계면의 법선 기울어짐을 실시간 생성했습니다.
* **해석적 햇빛 패치:** 창문을 통해 바닥에 드리워지는 햇빛 줄기를 수학적으로 해석했습니다. 창문 위치에서 가우시안 분포($\sigma=1.0m$)를 합산하고 안쪽으로 들어올수록 지수 함수로 광량을 감쇄시킨 뒤, **가산 블렌딩(`GL_ONE`, `GL_ONE`)**으로 바닥 픽셀에 빛 에너지를 직접 더해주었습니다.

### 4️⃣ 인터랙션 및 동적 이펙트 (Interaction & Dynamics)
* **Ray Casting & 스텐실 아웃라인:** 카메라 시점 벡터(Ray)와 오브젝트의 **AABB(축 정렬 경계 박스)** 교차 판정을 수행합니다. 3초 이상 호버링 시 외부 웹 URL로 이동하며, 타겟팅된 가구는 **스텐실 테스트**를 거쳐 노란색 외곽선이 활성화됩니다.
* **지오메트리 셰이더 폭발 효과:** 인터랙티브 요소로서 사용자가 `G` 키를 누르면 지오메트리 셰이더가 기존 정점 구조를 실시간 분해 및 제어하여 유리 화병이 파편으로 산산조각 나는 폭발 연출을 수행합니다.
* **동적 메시 & 파티클:** 공기 중 먼지 280개는 상시 카메라를 대면하는 **빌보드(Billboard)** 방식으로 렌더링되며 `glBufferSubData`로 동적 업로드됩니다. 실시간 움직이는 강아지는 사인 함수 기반의 걷기 사이클에 맞춰 **매 프레임 CPU에서 정점 데이터를 재생성하는 동적 메시** 기법을 채택했습니다.

## 🕹️ 조작 방법 (Controls)

| 키 바인딩 | 기능 설명 |
| :--- | :--- |
| `W`, `A`, `S`, `D` | FPS 스타일 플레이어 이동 (이동 시 사인파 카메라 워킹 적용) |
| `Mouse` | 마우스 시점 회전 (가구별 AABB 충돌 박스로 이동 제한 구현) |
| `F` | 천장 메인 점광원(Point Light) ON / OFF |
| `L` | 책상 양옆 플로어 램프 토글 (조명 분위기 전환) |
| `G` | 유리 화병 폭발 인터랙션 (지오메트리 셰이더 가동) |
| `Mouse Hover` | 액자, 책상, 트로피 3초 조준 시 스텐실 아웃라인 활성화 및 관련 URL 연동 |
